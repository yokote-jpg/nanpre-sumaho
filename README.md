■ About This Software
This software is a tool for creating Sudoku puzzles and solving them with automatically displayed candidate numbers.
When generating puzzles, you can select the difficulty level (Easy, Normal, Hard, Expert) and solving techniques (Any, Naked Pair, Naked Triple, Hidden Pair, Pointing Pair, Box-Line Reduction, X-Wing, XY-Wing) to create puzzles that match your preferred level.

■ Startup Password
Password: Included in the downloaded file

■ System Requirements
- Smartphone (iPhone, Android)

■ How to Use
1. Access the URL and enter the password.
2. Press the "Create" button.
3. Select the difficulty and solving techniques.
4. If needed, press the "GET" button to display candidate numbers.
   All candidate numbers will be displayed instantly.
5. Use the "Memo" button to switch between answer input and candidate input modes.
   * If an incorrect number is entered as an answer, it will be displayed in red.
     Press the ← key on the number pad (bottom right) to undo.
6. After completing a puzzle, press the "CLR" button to clear the grid,
   then create a new puzzle.

■ Button Descriptions
- Create : Generates a puzzle with the selected difficulty and techniques
- GET    : Calculates and displays candidate numbers
- CLR    : Clears the entire grid
- END    : Exits the application
- Memo   : 
   ON  (right) = Add/Delete candidate numbers
   OFF (left)  = Enter answer numbers

■ Notes
- This software assists in creating Sudoku puzzles, displaying candidate numbers, and solving them. It does not guarantee a unique solution (multiple solutions are not supported).
- There is no function to automatically generate and display the solution.
